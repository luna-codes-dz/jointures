## 🚀 Quick Start

### For End Users
1. Read the [User Guide](USER_GUIDE.md) for complete instructions
2. Follow the installation steps in the main [README](../README.md)
3. Launch the application with `npm start`

### For Developers
1. Review the [Architecture Documentation](ARCHITECTURE.md) to understand the codebase
2. Set up your development environment using the [Development Guide](DEVELOPMENT.md)

- Documentation is updated with each feature addition
